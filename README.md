### RSLS
A `ls` written in Rust.

Current Stage (Might not update further):
`ls` for normal output (filtering files starting with `.`)
`-a` for all files (including files starting with `.`)
`-l` for long format output (***Only including `file_mode` for `r`,`w`,`x`***)

Not implemented yet:
- [] `-l` with owner, edit time and so on...
